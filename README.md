Welcome to the **Pratham App Hub**, a next-generation web ecosystem built entirely with pure HTML, CSS, and Vanilla JavaScript. Designed with a "Light Console Gaming" aesthetic, this hub serves as a central launcher for a collection of custom-built web apps and games.

🔗 **Play it live here:** [https://pratham.github.io](https://pratham.github.io)

---

## ✨ Ecosystem Features

### 1. ♟️ Pro Chess Engine
A fully-featured, tournament-grade chess application.
* **Advanced Rules:** Fully supports Castling, En Passant captures, and Auto-Promotion (with UI selection modal).
* **Blitz Timers:** Built-in 10-minute countdown clocks for both White and Black.
* **Move Validation:** Custom logic engine prevents illegal moves and detects Check, Checkmate, and Stalemate.
* **Time Travel:** "Undo" functionality that restores exact board state and clock time.
* **Classic UI:** Features professional Staunton vector pieces and a classic Green/Cream board.

### 2. ❌ Tic Tac Toe (Impossible AI)
A tactical 1v1 arena against an unbeatable machine.
* **Minimax Algorithm:** The AI analyzes all possible future moves to ensure it never loses. You can only draw or lose.
* **Neon Aesthetics:** Sleek cyan and pink gradients with mechanical button presses.

### 3. 🐦 Flappy Bird (Retro Arcade)
A physics-based arcade challenge built on the HTML5 `<canvas>`.
* **Custom Physics Engine:** Tuned gravity and velocity for smooth, responsive tapping.
* **Infinite Generation:** Procedurally generated pipe obstacles and collision detection.

### 4. 🧮 Calculator (Math Engine)
A high-speed mathematical engine for daily use.
* **Tactile UI:** Keys are designed to mimic the feel of mechanical keyboard switches.
* **Precision Logic:** Handles float limits, sequential operations, and standard arithmetic with zero overflow errors.

### 5. 🔒 System Gateway (Login)
A sleek security gateway that protects the hub.
* **Local Storage:** Uses browser `localStorage` to manage session states.
* *(Default test passcode: 1234)*

## 🎨 UI / UX Design Philosophy

This project was built to look like a **Next-Gen Gaming Console Interface** (similar to PS5 or Nintendo Switch menus).
* **Responsive & Mobile-Locked:** Viewport settings ensure apps feel native on mobile (no accidental zooming or horizontal scrolling).
* **Vibrant Vector Graphics:** All app icons and game pieces are rendered using scalable SVGs, ensuring they remain razor-sharp on high-end OLED phone screens.
* **Haptic Audio:** Integrated crisp SFX for piece movements and captures.
